# Tin Dog Project

## Overview

The Tin Dog project is part of a code-along in my Udemy course. This project is focused on building a responsive and visually appealing website using **Bootstrap**. The website showcases a fictional dating app for dogs called "Tin Dog," and it includes multiple sections like testimonials, features, and pricing.

## Technologies Used

- **HTML**: For structuring the webpage.
- **CSS**: For custom styling.
- **Bootstrap**: For responsive layout and design components.

## Features

- **Responsive Design**: The website is fully responsive, thanks to Bootstrap's grid system and components.
- **Multiple Sections**: Includes a hero section, testimonials, features, and pricing tables.
- **Modern UI**: Styled using Bootstrap to achieve a professional, modern look.

## Getting Started

To run the Tin Dog project locally, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Ranjan-n/Tin-Dog-Project.git
   ```

2. **Navigate to the project directory**:
   ```bash
   cd Tin-Dog-Project
   ```

3. **Open `index.html` in your web browser**:
   You can open the file directly or use a local server.
